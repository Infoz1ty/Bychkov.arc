# Розумний захищений архіватор файлів SARC v1

Семестровий проєкт із дисципліни «Алгоритми та оптимізація програмних рішень».

## Про проєкт

**Рівень складності:** Базовий  
**Цільова платформа:** .NET 8.0+ (C#)

### Що робить система?
Консольний архіватор та розархіватор файлів власного бінарного формату **SARC v1**:
1. **Аналіз вхідних даних:** приймає один або декілька довільних файлів будь-яких типів. Перцептрон аналізує кожен файл за вектором ознак, класифікує його на один із семи типів та визначає стратегію: стискати чи зберігати без стиснення (`NO_COMPRESSION`), якщо стиснення неефективне.
2. **Стиснення:** розбір на повтори через жадібний / лінивий LZ77 та побітове кодування канонічним Гаффманом.
3. **Пакування:** розбиття на блоки та оптимальний розподіл по томах фіксованого розміру за допомогою алгоритму рюкзака 0/1.
4. **Криптографічний захист:** схема Encrypt-then-MAC — генерація ключів через PBKDF2 (100 000 ітерацій), шифрування AES-256-CTR (унікальний nonce на кожен том) та код автентичності HMAC-SHA256.
5. **Відновлення:** побайтово точне відновлення вихідних файлів (`original == restored`) із перевіркою CRC32 та довжини.

## Збірка та тестування

Збірка рішення:
```shell
dotnet build SmartSecureArchiver.sln

Запуск автоматичних тестів:
dotnet test

Використання консольної утиліти (CLI)
1. Архівування файлів
dotnet run --project src/SmartSecureArchiver.Cli -- archive -i file1.txt file2.bin -o archive.arc -p "algo2026"
2. Розархівування
dotnet run --project src/SmartSecureArchiver.Cli -- extract -a archive.arc -o ./restored/ -p "algo2026"
```
Параметри командного рядка
-i, --input — список вхідних файлів для додавання в архів.

-o, --output — шлях до вихідного архіву (.arc) або каталог для розпакування.

-p, --password — пароль для генерації ключів шифрування та HMAC.

-a, --archive — шлях до архіву для розпакування.
